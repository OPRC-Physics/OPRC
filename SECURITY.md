# OPRC Security Policy

## ⚖️ Our Philosophy
The Open Physics Research Collective (OPRC) operates under a mandate of Radical Transparency. However, we recognize that vulnerabilities in our computational models or infrastructure can undermine scientific consensus. We are committed to a responsible disclosure process.

## ✅ Supported Versions
Only the latest release is actively supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.1.x  | :white_check_mark: |
| < v1.1  | :x:                |

## 🚀 Reporting a Vulnerability
**Do not open a public Issue for security vulnerabilities.**

If you discover a vulnerability in our simulation code, data integrity pipelines, or OPRC infrastructure, please follow these steps:

1. **Email:** Send a detailed report to `droiindia@gmail.com`.
2. **Details:** Include the affected Project (e.g., Project Alpha), the nature of the flaw (e.g., code injection in Dockerfile), and a proof-of-concept.
3. **Response:** You will receive an initial response within 48 hours.

## 🤝 Disclosure Policy
Once a fix is merged into `main`, we will publish a **Security Advisory** and credit the researcher in our `CONTRIBUTORS.md`.
